# AI 绘本生成（故事 → 翻页绘本书）

把一个故事变成一本**单文件 HTML 拟真翻页绘本书**：纸页弯折、页角卷曲跟手、base64 内嵌全部图片，产出一个 `.html` 双击即读、离线可开、可直接分发。

本流程已在真实活动筹备中全链路验证（双角色 12 页零形象漂移、中文书名/路牌零错字、全书 GPU 生成 ~2 分钟）。

## 前提：生图服务端

需要一个自部署的 **Qwen-Image-2.1 服务端**（v2+，带串行网关），支持：

- `POST /v1/images`（文生图，`fast` 加速参数）
- `POST /v1/edits`（图生图/参考图编辑，`image2`/`image3` 多参考）
- `GET /queue`（排队可视化）

服务地址**不要写进任何文件**，通过 `--base` 参数或环境变量 `QWEN_IMAGE_BASE` 传入。本机部署实例的真实地址、服务端源码与运维细节见本地记忆（`project_salon_06_picture_book`）或对应项目纪要；服务端 API 完整契约见 `references/api.md`。

## 四步流程（核心方法论）

### 第 1 步：故事分镜

把故事拆成 **8–12 页**，每页一句话 caption（≤50 字，童书节奏）。每页同时想清楚画面（这决定第 3 步的 prompt），标注哪几页是"大场面"（远景/俯瞰/仰视等复杂构图，后面要挂构图参考）。

### 第 2 步：定妆照（anchor，quality 档）

用 **quality 档文生图**生成一张"角色定妆照"：所有角色同框、全身、浅色干净背景、无场景。这张图是全书的形象锚点——后面每一页都从它出发编辑，**不要链式传递**（每页从上一页 edit 会误差累积，几页后角色漂移）。

定妆照阶段同时**定死风格串**（见 references/methodology.md 选型表）。立体感/画风由风格串整体决定，想换就重做定妆照，不要在旧风格串上打补丁（往平面风格里加"体积光"等词无效，实测过）。

### 第 3 步：逐页生成（fast 档 edits）

每页调 `/v1/edits`，`image` 永远传定妆照：

- **普通页**（单参考）：prompt = `KEEP 锁定串 + "。新场景：" + 四要素场景 + "，" + 风格串`
- **大场面页**（多参考）：先用 fast 文生图生成一张"简笔剪影构图示意"（~6s/张），再作为 `image2` 传入。prompt 开头声明："Picture 1 是角色定妆照，Picture 2 是构图参考。以 Picture 1 为准保持角色形象与画风完全不变，严格按 Picture 2 的构图与景别安排画面布局…"

**四要素**：每页场景描述显式写全 —— 景别（远景/中景/近景/特写）、机位（平视/仰视/俯瞰）、姿态（角色在做什么）、位置（谁在画面哪里）。单图 edits 会连构图一起继承定妆照，不显式写四要素整本书每页都长得一样（实测坑）。

**中文文字**：书名、招牌、路牌等短文字直接写进 prompt 并用「」括出（如`画面顶部手写体中文大标题「书名」`），quality 与 fast 档都可靠；长文案海报排版未充分验证，控制在一行内。

### 第 4 步：组装

`build_book.py` 把封面 + 内页图 + caption 组装成单文件翻页书（StPageFlip 拟真翻页引擎，MIT，44KB 内嵌；支持 `#页码` 深链、键盘/触屏翻页、reduced-motion）。厚涂风格 PNG 体积大（14 页可到 30MB+），在意加载速度可先把图片压 JPEG 再组装。

## 快速上手

全部配置写在一个 `story.json`（字段 schema 与示例见 `assets/story.example.json`），两条命令完成：

```bash
# 生成全部图片（anchor quality + 其余 fast；断点续跑，已存在的图自动跳过）
python scripts/gen_book.py story.json --base "$QWEN_IMAGE_BASE" --out ./out

# 生成完直接组装（或图片已齐时只组装）
python scripts/gen_book.py story.json --out ./out --build-only ./我的绘本.html
```

`gen_book.py` 自动设置 `NO_PROXY=*`（内网请求被本机代理劫持会 502，实测坑）、失败自动重试 2 次、打印服务端 `X-Mode`/`X-Elapsed-Sec` 头。

改书的样子（页面版式、翻页手感）改 `scripts/build_book.py` 内的 TEMPLATE 后重新组装即可。
