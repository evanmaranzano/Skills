# Super Handoff — 会话交接与续作

综合 392fyc/claude-handoff（结构化 Starting Prompt）、NotThatRob/Session-Handoff（git 现场核对、150 行上限）、maaarcooo/agent-skills·handoff（链式引用前一篇）、claude-session-rhythm（resume + 漂移检查）四个开源实现，叠加本机约定（`~/.agents/rules/feedback-communication.md` HANDOFF 命名规范、凭据红线、file:/// 链接交付）。

默认交接目录：`C:\Users\26566\DeskBox\文档\交接HANDOFF`（用户指定其他目录时优先）。

## 方向判定

- 用户要**写**交接（会话要结束、上下文将满、存档当前进度）→ 走 [写流程](#写流程)。
- 用户要**续**（继续上次的任务、读交接、新会话被指了交接文档）→ 走 [读流程](#读流程)。

# 写流程

1. **目录勘察**：列出交接目录全部 `HANDOFF*.md`。新建 `HANDOFF-<事件名>-<日期>.md`（事件名从当前任务提炼，连字符分隔，如 `HANDOFF-molispark海报LoRA润色-20261104.md`）。**绝不覆盖任何已有文档**；仅同一事件续写时更新同名文件。文首一行链接指向本事件前一篇（按日期判断），没有前篇则省略此行。
2. **事实核对（写前必做）**：对文档涉及的每个 git 仓库跑 `git log --oneline -3` + `git status`，以输出为准写 commit hash 和仓库状态，**不凭会话记忆写**。服务在线状态、端口、文件路径有疑点就现场核验（curl/ssh/ls），核验不了的在文中标注"未核验"。
3. **七节骨架**（顺序固定）：
   1. **任务背景**——机器/服务/仓库/关键文件的**真实绝对路径**，读流程需要的工作区定位
   2. **已完成**——每条带验证证据（命令输出、测试结果、验收人），与"我认为做完了"区分
   3. **当前状态**——没有卡点就如实写"无阻塞"三个字，**禁止编造卡点**；有卡点写清最小解锁条件
   4. **下一步**——按优先级排序，首条是"新会话拿起来就能干"的具体动作
   5. **绝对不要再踩的坑**——硬边界、权限约束、纪律、踩过的技术坑，各附一句来源或后果（如"用户明确要求""曾导致 XX"）
   6. **命令速查**——机器、端口、服务名、部署/重启/验证常用命令，新会话免翻历史
   7. **凭据与安全注记**——只写文件路径 + 警告（如"zip 内含明文 token，不可入库，活动后吊销"），**不写任何值**；无则整节省略
4. **约束**：全文 ≤150 行、30 秒可读完；写给零上下文读者（不写"我做了"，写清对象与位置）；未验证推断标注"待核"；不记录密码、token、key、连接串、Cookie。
5. **交付**：写完向用户给出 `file:///` 可点击超链接（正斜杠路径），一句话说明文档名和事件。

# 读流程

1. **定位**：读用户指定的交接文档；未指定则在默认目录按文件名日期取**最近一篇**，多个事件并存时列出候选让用户选或按用户口述事件名匹配。
2. **漂移检查**：对文档声明的事实做现场核验——git 仓库状态（log/status）、关键服务与健康状态、关键文件是否存在。逐项列出"文档说 X / 现场是 Y"差异；无差异也明确说"已核对 N 项无漂移"。
3. **冲突处理**：现场为准。文档过时的部分顺手更正（保持单文档最新，不另建新篇），重大冲突先向用户报告再动。
4. **续作**：按文档"下一步"首项直接开始干活（用户已授权的延续性工作不重新请示）；执行中新产生的事实按本地记忆规则沉淀。
